# NovaCloud 完整链路学习手册设计

## 目标

将项目现有的登录、Redis 会话、网关鉴权、限流、应用层中转、中台层处理、MySQL 查询和 TraceId 日志串成一份适合初学者顺序阅读的主学习文档。

## 写法

- 主线按真实用户动作组织：打开页面、登录、查询工单、退出、按 TraceId 查日志。
- 每一章固定回答：请求从哪里来、当前层收到什么、核心代码在哪里、代码逐行做什么、下一跳是谁、Redis/MySQL 如何变化、失败在哪里返回。
- 核心代码只摘取必要片段，并在片段后逐行翻译；不整文件复制。
- 所有当前行为以源码、配置和《搭建日志.md》的验收记录为依据。
- 严格区分当前实现、教学简化和真实生产项目还需补充的能力。

## 文档结构

扩充项目根目录的《学习文档.md》，包含系统全景、代码阅读方法、登录链路、数据归属、带会话查询、三层鉴权、失败状态、网关与限流、TraceId、Redis、Nacos 与 Docker、动手实验和代码索引。现有 `docs/*学习与操作.md` 保留为专项操作参考。

## 边界

- 不修改任何业务代码、配置或运行脚本。
- 不把 Kafka、JWT、集中日志平台、span 追踪或 Kubernetes 写成已实现能力。
- 不在文档中输出 `.env` 的真实密码、Redis 密码或会话 token。
