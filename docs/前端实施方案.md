# 浏览器操作页面

按用户已确认的方案，增加登录、当前用户、工单查询、退出、错误提示和 TraceId 信息。使用原生 HTML/CSS/JavaScript，由现有 Nginx 在根路径提供，API 路由不变，不添加前端框架或新的运行容器。

- 页面分为账号、工单、最近一次请求三个区域，支持桌面与手机宽度、键盘操作和读屏提示。
- token 仅保存到当前页面内存，不存 localStorage/sessionStorage，不显示或写入日志；刷新需重新登录。
- 登录成功后读取 /api/auth/me；401 清除失效会话，403 保留登录并提示无权限，404 清除旧工单并提示不存在，429 展示各接口等待时间，503/超时允许重试。
- 请求进行中禁用重复提交；退出成功后清除当前用户和工单。退出失败保留会话，提示重试，避免把本地清理误说成服务端退出成功。
- 接口内容通过 textContent 渲染；请求信息只展示方法、路径、HTTP 状态、耗时和 TraceId，不展示密码、token 或完整响应正文。
- Nginx 只新增根页和明确的静态文件路径，未知路径继续 404。页面不预填密码、不读取 .env，操作者自行从本地文件取得演示密码。

验收：真实浏览器登录、查询、404、observer 的 403、退出、401、429 倒计时和网络错误；桌面/窄屏截图、静态资源与原 API 回归。真实链路与模拟异常验收分别记录。
